existem três tipos de casa (fora a dos cantos)
primeiro tipo: Propriedade
variaveis da propriedade
String nome 
int proprietario
int preco  
int grupo
int alugel
int precoCasa
int precoHotel

você só pode comprar uma casa pra propriedade depois que você já tiver todas as propriedades daquele grupo

segundo tipo: companhias
variáveis da companhia
String nome
int preco
int proprietario
int valorConta
